# ISTAT PULSE DATA

Pacchetto dati pubblico di ISTAT PULSE basato su dati pubblici ISTAT.

Questo repository contiene esclusivamente gli script minimi di aggiornamento e i file dati necessari all'app ISTAT PULSE. Non contiene il codice dell'applicazione.

Fonte attiva: DEMO ISTAT – Bilancio demografico mensile.

ISTAT PULSE è un prototipo indipendente. Non è un prodotto ufficiale ISTAT.
